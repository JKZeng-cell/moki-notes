# 0.1.4 source update / 源码更新

Repository checks: `npm run check` passed (type checking, 42 test files / 178 tests, production build); `npm run test:mcp` passed all 13 smoke checks.

## 中文

- 知识树缩放到 150% 及以上时显示完整便签名；缩小时恢复 10 个字素的简写。
- 长标题自动分行，英文优先在单词之间换行，不拆开组合表情符号。
- 标题屏幕字号上限为 18px，避免持续放大时文字占满画布；Agent 检索提示随标题行数下移。
- 保持现有节点布局、平移、关联与双击打开操作。

本地已通过类型检查、生产构建及隔离 Windows 应用验证：按钮和滚轮缩放往返、长中文与英文标题、组合 Emoji、深色小窗口、中键平移、双击打开。最终 0.1.4 安装版也通过显示核对。

本次只同步源码，不发布新的 GitHub 安装包。[公开安装包](https://github.com/JKZeng-cell/moki-notes/releases)仍以 Releases 页面为准。

## English

- Show complete note titles in the knowledge graph at 150% zoom and above; restore the ten-grapheme abbreviation when zooming out.
- Wrap long titles, prefer word boundaries for English, and preserve combined emoji sequences.
- Cap title text at 18 screen pixels and move the Agent search indicator below all title lines.
- Preserve node layout, panning, connections, and double-click navigation.

Local validation covered type checking, production build, button/wheel zoom in both directions, long Chinese and English titles, combined emoji, a narrow dark-theme window, middle-button panning, and double-click navigation in an isolated Windows app. The final 0.1.4 packaged application was also checked visually.

This update publishes source only, not a new GitHub installer. See [Releases](https://github.com/JKZeng-cell/moki-notes/releases) for published binaries.
