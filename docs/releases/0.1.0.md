# MOKI Notes 0.1.0 / MOKI便签 0.1.0

## 中文

[下载 Windows x64 安装包](https://github.com/JKZeng-cell/moki-notes/releases/download/v0.1.0/MOKI-Notes-Setup-0.1.0-x64.exe) · [源码与说明](https://github.com/JKZeng-cell/moki-notes)

下载并运行 `MOKI-Notes-Setup-0.1.0-x64.exe`，按向导选择安装目录，即可启动。安装包包含运行环境与飞书 CLI，无需另装 Node.js / npm。

- 本地 Markdown 实时编辑、任务清单、表格、代码、公式及分栏。
- 独立桌面便签、知识树与跨便签关联。
- MCP 搜索、读取、新建和版本校验更新，支持接入本地 Agent。
- 图片与文件附件、版本历史、TXT / MD / DOCX 导出及完整迁移。
- 飞书云盘同步，以及 Markdown / TXT 多选批量导入。

安装包目前未签名，Windows 可能显示未知发布者提示。飞书同步需要自行授权与配置；Agent 协作需要支持本地 stdio MCP 的客户端。当前仅提供 Windows x64 安装包，macOS / Linux 尚未实机验证。

SHA256 校验文件随 Release 提供。本地验证覆盖类型检查、165 项测试、构建、MCP、NSIS 与内嵌应用完整性，以及隔离环境中的应用启动和真实文件多选导入。未在本轮覆盖已有安装或执行卸载。

## English

[Download the Windows x64 installer](https://github.com/JKZeng-cell/moki-notes/releases/download/v0.1.0/MOKI-Notes-Setup-0.1.0-x64.exe) · [Source and documentation](https://github.com/JKZeng-cell/moki-notes)

Download and run `MOKI-Notes-Setup-0.1.0-x64.exe`, choose an install location in the setup wizard, and launch the app. The runtime and Feishu/Lark CLI are included; Node.js and npm are not required for normal installation.

- Live local Markdown editing with tasks, tables, code, formulas, and columns.
- Desktop sticky cards, a knowledge tree, and cross-note links.
- Local MCP search, read, create, and version-checked updates for Agent clients.
- Images and attachments, version history, TXT / MD / DOCX exports, and full migration.
- Feishu Drive sync and multi-file Markdown / TXT import.

The installer is currently unsigned, so Windows may show an unknown-publisher prompt. Feishu sync requires your own authorization/configuration, and Agent collaboration requires a client supporting local stdio MCP. Only Windows x64 installers are provided; macOS/Linux desktop behavior is not verified.

The Release includes a SHA256 checksum file. Local validation covers type checking, 165 tests, build and MCP checks, NSIS/payload integrity, isolated app launch, and real multi-file import. This release verification did not replace or uninstall an existing installation.
