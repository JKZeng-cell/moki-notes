# 0.1.3 source update / 源码更新

This source update includes changes from local versions 0.1.2 and 0.1.3. It does not publish a new GitHub binary release.

Repository validation: `npm run check` passed (type checking, 42 test files / 178 tests, production build); `npm run test:mcp` passed all 13 smoke checks.

## 中文

- 在「设置 → 偏好设置」增加「开机自启动」，默认关闭。Windows 安装版开启后，在登录系统时自动运行。
- 开关读取系统实际状态，修改后回读确认；从系统设置返回应用时刷新状态。开发环境和不支持的平台禁用此开关。
- 卸载时仅清理属于本安装目录的启动项，升级时保留设置。
- 修复持续运行后新打开的桌面便签出现页面资源加载 500 的问题。桌面服务在启动时载入界面资源，后续窗口复用相同资源。
- 修复错误响应残留 HTML/图片类型和长度信息导致原始错误被掩盖的问题。
- 新增启动项及桌面资源回归测试，覆盖系统禁用、写入失败、无缓存加载、HEAD/ETag 与错误响应。

本地 Windows 安装包验证覆盖真实启动项开关、应用重启后的状态读取，以及桌面卡片冷加载、编辑和重启恢复。未通过重启 Windows 验证系统登录；卸载清理已通过安装器编译，本轮未执行实际卸载。公开安装包请查看 [Releases](https://github.com/JKZeng-cell/moki-notes/releases)。

## English

- Add an opt-in Windows launch-at-login switch under Settings → Preferences, disabled by default.
- Read the actual system startup state, verify changes after writing, and refresh when the app regains focus. Disable the control in development builds and on unsupported platforms.
- Remove only this installation's startup entry on uninstall; retain it during updates.
- Fix desktop sticky cards returning HTTP 500 for page resources after prolonged use. Load bundled UI resources once when the desktop service starts and reuse them for subsequent windows.
- Clear stale response headers before reporting errors so HTML/image failures do not mask their original cause.
- Add regression tests for startup settings, system disablement, rejected writes, desktop resource loading, HEAD/ETag handling, and error responses.

Local Windows packaged-app checks covered native startup registration/removal and state after application restart, plus cold sticky-card loading, editing, and restoration. Windows itself was not rebooted; uninstall cleanup was compiled but not exercised through an actual uninstall in this round. See [Releases](https://github.com/JKZeng-cell/moki-notes/releases) for published installers.
