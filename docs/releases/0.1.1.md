# MOKI Notes 0.1.1 / MOKI便签 0.1.1

## 中文

[下载 Windows x64 安装包](https://github.com/JKZeng-cell/moki-notes/releases/download/v0.1.1/MOKI-Notes-Setup-0.1.1-x64.exe)

- 图片放大预览支持右键复制图片、复制原文件、另存为、复制链接和默认应用打开；菜单自动避让窗口边缘，操作结果在预览内提示。
- 图片和本地附件支持复制到系统剪贴板，直接粘贴到支持图片或文件的应用；选中文字后支持右键编辑与格式操作。
- 便签最近编辑时间增加时分，统一使用本地时间及 24 小时制。
- “我的收藏”支持从卡片或右键菜单取消收藏，并保存当前便签的编辑内容。
- 改善 Windows 更新时的保存退出流程、MCP 后台进程识别及超时提示；重建新版本的 HTTP 缓存，保留旧缓存和本地草稿。

安装包内含运行环境与飞书 CLI，无需额外安装 Node.js。旧版本在更新时可能仍需在便签窗口确认“保存并关闭”；保存冲突或失败会阻止退出。建议更新前通过“设置 → 数据与存储”导出完整备份。

当前安装包未签名，Windows 可能显示未知发布者提示。仅提供 Windows x64；macOS/Linux 未实机验证。图片复制为静态 PNG，复制原文件保留原始格式；外部应用需要支持相应的粘贴类型。

## English

[Download the Windows x64 installer](https://github.com/JKZeng-cell/moki-notes/releases/download/v0.1.1/MOKI-Notes-Setup-0.1.1-x64.exe)

- Enlarged image previews now offer a context menu for copying images/original files, saving, copying links, and opening the default application. Menus stay inside the viewport and show feedback within the preview.
- Copy images and local attachments to the system clipboard for pasting into compatible apps. Selected text also supports editing and formatting context actions.
- Note modification times now include hours and minutes in local, 24-hour time.
- Remove favorites directly from cards or their context menus while saving current edits.
- Improve save-and-close during Windows updates, MCP background process detection, and timeout messages. Refresh HTTP caches for new builds while preserving previous caches and local drafts.

The installer bundles the runtime and Feishu/Lark CLI. Older versions may still ask for Save and Close inside the app during an update; save conflicts or failures prevent exit. A complete backup is available in Settings → Data and Storage.

The installer is unsigned. Only Windows x64 is provided; macOS/Linux are not verified. Copy Image produces a static PNG; Copy Original File preserves the original format. The destination application must support the clipboard type.

SHA256 checksums are included with this release.
